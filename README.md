# LittleQ

LittleQ 是面向 K12 学生（小学到初中）的开源 AI 编程与创作 Web 平台：学生在小黄鸭
Little Q 的陪伴下，通过对话式 Vibe Coding 借助 AI 完成小工具、网页小游戏、小动画、
绘本等作品，并一键发布到网上供浏览与分享；同时为家长与老师提供开号、分组、任务与
课堂等教学/家庭支撑。平台开源自部署、单实例单租户，账号只有成人（家长/老师）与
学生两层。

> **本项目未做法律合规评审，公开或学校场景部署前请自行评估。**

> ⚠️ **面向未成年人**：本平台的使用者是孩子。谁部署、谁运营，谁就对其平台上的内容
> 与未成年人使用负责；平台提供内容安全能力（沙箱、扫描、举报、成人总开关），但不
> 代替部署者承担运营责任。形态 B/C 的部署者还须自行遵守所选托管平台的服务条款。

## 当前状态

M0（设计与验证）阶段：仓库目前只有许可证、治理文件与 CI 门禁骨架，**尚无任何业务
代码，技术栈待架构设计评审后确定**。

## 部署形态与优先级

| 形态 | 承载 | 优先级 | 适用场景 |
| --- | --- | --- | --- |
| A | 自有服务器 / NAS + Docker Compose | **P0（首个交付形态）** | 班级（20–40 并发）与学校场景的唯一推荐；数据在本地 |
| B | Vercel | 第一优先（Serverless） | 家庭 1–3 个孩子，零运维、免费额度起步 |
| C | Cloudflare | 第二优先（Serverless） | 同形态 B，作为备选 |

三种形态**不等价**：形态 B/C 运行在 Serverless 上，无常驻进程，课堂模式等能力按
PRD 第 4 章降级；整个班级上课请使用形态 A。

## 部署前置条件（明示）

- **部署者必须自备 QCA（Qoder Cloud Agents）账号与额度**——QCA 是平台唯一的
  Agent 运行时，无 QCA 凭证则 Vibe Coding 与内容创作均不可用。
- 可选：阿里云百炼 API Key（生图、语音等多模态内容创作，可留空后补）。
- 凭证只在你自己的部署实例服务端持有，平台代码不会将其下发到浏览器；项目方不经手、
  不代收任何部署者凭证。
